# CardioTwin AI

AI-powered Heart Disease Prediction using Bayesian Networks and Explainable AI.

## Features
- Bayesian Network Prediction
- Risk Analysis Dashboard
- Explainability Center
- What-If Simulator
- PDF Report Generation

## Tech Stack
- React
- TypeScript
- FastAPI
- pgmpy
- XGBoost
- SHAP

## Run

### Backend
cd backend
pip install -r requirements.txt
uvicorn main:app --reload

### Frontend
cd frontend
npm install
npm run dev
